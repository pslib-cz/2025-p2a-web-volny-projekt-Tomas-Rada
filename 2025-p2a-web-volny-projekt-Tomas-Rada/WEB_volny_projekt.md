# 2 Očekávané výstupy

## 2.1 Koncept projektu a příprava obsahu

- Textový obsah generujte např. s Gemini, ChatGPT apod.
- Obrázky generujte např. Canva AI, Leonardo AI.
- Ikony a piktogramy: IcoMoon App - Icon Font, SVG, PDF & PNG Generator.

## 2.2 Grafický návrh

- Kompletně zpracovaný grafický návrh webové stránky v nástroji Figma.
- Držte průběžně aktualizované k nahlédnutí a hodnocení.
- Návrh pro mobil (např. 360w) až desktop (2540w).
- Počet vizuálních skic odpovídá reálnému počtu změn layoutu.

### Doporučení

- Web navrhujte tak, aby splňoval definované cíle.
- Využívejte layout grid.
- Paletu barev a písma definujte přes local styles.
- Pro flex chování využívejte auto layout.
- CTA prvky navrhujte dostatečně velké pro mobil.
- Standardní velikost textu: 16px.
- Zohledňujte thumb rule design.

## 2.3 Webová stránka

- Plně responzivní a mobile-first.
- Obsahuje favicon.
- Navigace odpovídá množství stránek.
- Zdrojový kód v branch `main`, build ve druhé větvi pro GitHub Pages.

### Rozsah webu

Minimálně 3 unikátní stránky webu, kde bude využito:

- Galerie v CSS Grid.
- Formulář (statický).
- CSS animace.

### Doporučení

- Pro layout používejte Grid.
- Pro vnitřní obsah flexbox nebo grid.
- Používejte CSS layers.
